A unified citizen-centric digital portal dedicated to accelerating **United Nations Sustainable Development Goal 1 (No Poverty / शून्य निर्धनता)** across India. The portal helps vulnerable households, rural workers, small farmers, street vendors, and women self-help groups discover eligible welfare schemes, simulate annual direct financial benefits, generate application checklists, and navigate government services with zero middlemen.

---

## 🏛️ Key Features

### 1. 🔍 "Know Your Schemes" — 3-Step Interactive Eligibility Wizard
- **Demographics Assessment:** Evaluates age, gender, social category (General, OBC, SC, ST), and disability status.
- **Socio-Economic Matching:** Evaluates rural/urban jurisdiction, state/UT, occupation (farmer, artisan, vendor, laborer, homemaker), income bracket, and Ration Card type (AAY, BPL, PHH, APL).
- **Need-Based Filtering:** Pins housing, healthcare, agricultural credit, clean cooking gas, and pension requirements.
- **Smart Scoring & Confetti:** Calculates real-time compatibility scores (%) with verified central/state welfare programs.

### 2. 📋 Comprehensive Welfare Directory & Scheme Explorer
- Authentic catalog of India's flagship poverty alleviation programs:
  - **PM-KISAN:** ₹6,000/year farmer direct income support.
  - **PMAY-Gramin & Urban:** ₹1,20,000 to ₹1,30,000 pucca housing grant + toilet incentive + MGNREGA wage support.
  - **Ayushman Bharat (AB-PMJAY):** ₹5,00,000/family free cashless secondary and tertiary hospital treatment.
  - **PM Garib Kalyan Anna Yojana (PMGKAY):** 100% free monthly foodgrains for 81+ crore NFSA beneficiaries.
  - **MGNREGA:** Legal guarantee of 100 days unskilled rural wage employment.
  - **PM SVANidhi:** Collateral-free working capital micro-loans (up to ₹50,000) for street vendors with 7% interest subsidy.
  - **DAY-NRLM & Lakhpati Didi:** Revolving and community investment funds for rural women Self-Help Groups (SHGs).
  - **National Social Assistance Programme (NSAP):** Monthly pensions for indigent elderly, widows, and severely disabled.
  - **PM Ujjwala 2.0:** Free deposit-free LPG gas connections + ₹300 refill subsidy.
  - **PM Surya Ghar (Muft Bijli):** Up to ₹78,000 rooftop solar subsidy + 300 free units/month.
  - **PM Vishwakarma:** ₹15,000 toolkit voucher + collateral-free loans @ 5% for traditional craftspersons.
- Rich scheme detail modals with eligibility rules, required documents, step-by-step application guidance, official helplines, and verified `.gov.in` portal links.

### 3. 💰 Direct Benefit Transfer (DBT) Financial Impact Simulator
- Simulates cumulative financial uplift when multiple schemes converge on a single household.
- Calculates total annual monetary transfer, free hospitalization coverage shield, and monthly relief equivalent.
- Benchmarks household security against the National Multidimensional Poverty threshold.
- Quick archetype presets: *Small Farmer Family*, *Houseless Rural Laborer*, and *Women SHG / Lakhpati Didi*.

### 4. 🖨️ Zero-Redundancy Document Checklist Generator
- Aggregates and deduplicates mandatory paperwork across multiple selected schemes (Aadhaar, NPCI DBT-enabled bank account, land records/RoR, income declaration, caste certificate).
- Interactive tracking: Mark documents as *Ready* or *Pending*.
- One-click print / export for citizens visiting Common Service Centres (CSCs) or Gram Panchayat offices.

### 5. 📊 NITI Aayog Multidimensional Poverty Index (MPI) Analytics
- Historical trend tracking India's headcount poverty reduction from 29.17% (2013-14) down towards single digits.
- State-wise rankings of citizens lifted from multidimensional poverty (Uttar Pradesh, Bihar, Madhya Pradesh, Rajasthan, etc.).
- Performance monitoring across 12 vital deprivation pillars (Nutrition, Clean Cooking, Electricity, Sanitation, Bank Accounts).

### 6. 🛡️ Citizen Helpdesks, CSC Locator & Anti-Fraud Advisory
- Official 24x7 toll-free directory (Kisan Call Centre 155261, Ayushman Bharat 14555, PMAY 1800-11-6446, Citizen Welfare 1800-11-0001).
- Single-tap phone number copy and direct dialing.
- Vigilance guidance against fraudulent middlemen and fake portals, ensuring citizens only trust official `.gov.in` / `.nic.in` domains.

### 7. 🌐 GIGW 3.0 Compliance & Accessibility
- **Multilingual Support:** Instant switching between English, हिन्दी (Hindi), తెలుగు (Telugu), தமிழ் (Tamil), and বাংলা (Bengali).
- **Accessibility Controls:** High Contrast mode toggle, font size adjusters (`A-`, `A`, `A+`), and screen-reader accessibility landmarks.
- **Personal Shortlist:** Bookmark schemes and view/print your saved welfare basket anytime.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended, tested on Node v22.12.0)
- npm (v9+)

### Installation & Execution

1. Clone or open the project directory:
   ```bash
   cd c:\Users\Sainath\OneDrive\Desktop\NAVEEN
   ```

2. Install dependencies (if not already installed):
   ```bash
   npm install
   ```

3. Launch development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
